# Обратная связь после пилота (12.6)

## A — педагог (после каждой сессии, 3 мин)

1. Псевдоним  
2. Интерес ребёнка (1–5)  
3. Понятны ответы агента? (да / частично / нет)  
4. Техсбой? (нет / да — что)  
5. Странные ответы? (текст или «нет»)  
6. Одна фраза: что улучшить  

→ строка в [METRICS_FORM.md](METRICS_FORM.md)

## B — методист (после волны 1)

1. Сценарий: длина / удачность  
2. Какие реплики заменить в YAML  
3. Нужен ли новый режим  
4. Неуместная память? (да/нет)  
5. Голос на волне 2? (да / нет / условия)  

## C — руководитель (итог 1 стр)

1. Продолжаем / пауза / стоп  
2. Топ-3 проблемы  
3. Топ-3 успеха  
4. Задачи разработке (приоритет)  
5. Задачи юристу / центру  

## D — разработчик

- Сводка логов: ошибки API, `security_incident`, latency  
- Список изменений на волну 2  

## Сроки

| Когда | Что |
|-------|-----|
| День 0 | A после каждой сессии |
| День +1 | Встреча 45 мин |
| День +3 | Итог C |
