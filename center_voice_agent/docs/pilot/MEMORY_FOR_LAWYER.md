## Что хранится технически

| Данные | Где | ПДн? | Кто пишет |
|--------|-----|------|-----------|
| `child_profile_id` | SQLite `child_profiles` | псевдоним | `create_child` / агент |
| `display_name`, `age_band` | `child_profiles` | возможно | центр (опционально) |
| `category` + `value_text` | `long_term_memory_entries` | зависит от текста | агент `memory_upsert` |
| Краткий диалог | RAM сессии | временно | сессия |
| Логи | stdout / файл | при `LOG_REDACT_USER_TEXT=true` — отпечаток, не полный текст | система |
