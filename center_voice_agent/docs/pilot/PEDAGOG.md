# Инструкция педагогу (12.3.1)

## До занятия

1. Спросить техконтакт: «пилот OK?»  
2. Распечатать фразу при сбое: *«Сейчас робот отдыхает, поговорим сами»*  
3. Заполнить [PASSPORT.md](PASSPORT.md) (дети, псевдонимы).

## Запуск (текст — проще для волны 1)

1. Дважды щелкнуть `scripts\start_pilot_text.bat`  
2. Дождаться «Готов» / приглашения ввести реплику  
3. Ребёнок говорит → педагог вводит текст → Enter → ответ читается  
4. 10–15 минут → закрыть окно  
5. Заполнить строку в [METRICS_FORM.md](METRICS_FORM.md)

## Правила в зале

- Взрослый **всегда** видит диалог  
- Не вводить адрес, телефон, полные ФИО  
- Странный ответ → стоп, живой разговор, звонок on-call ([ONCALL.md](ONCALL.md))

## Голос (если включён)

Запуск через «Арину» / бот — только по инструкции техконтакта. Микрофон проверить за 2 мин до детей.

## Репетиция без детей

20 мин: запуск bat → 2–3 реплики → закрытие → метрика.
