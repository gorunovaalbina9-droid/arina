## Уровни

| Уровень | Действие педагога | On-call |
|---------|-------------------|---------|
| L1 | Зависло / нет ответа → запасная фраза | — |
| L2 | Модерация заблокировала фразу → записать в метрики | — |
| L3 | Нежелательный ответ **мимо** модерации → **стоп** сессии | ≤15 мин |
| L4 | Утечка ПДн / жалоба родителя → стоп пилот | немедленно |

## L3: шаги on-call

1. Стоп сессий (см. [SUCCESS_CRITERIA.md](SUCCESS_CRITERIA.md) S1).  
2. Сохранить `correlation_id` из лога (без лица ребёнка).  
3. Правка `config/moderation.yaml` → `blocked_substrings`.  
4. При необходимости: `tool_ids` без `web_search`.  
5. Запись в [INCIDENT_LOG.csv](INCIDENT_LOG.csv).  
6. Решение руководителя: продолжать сегодня или нет.
