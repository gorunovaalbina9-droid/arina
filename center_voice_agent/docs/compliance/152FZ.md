# Соответствие 152-ФЗ и трансграничной передаче (шаблон для центра)

Документ для юриста и администрации центра. Код агента **не заменяет** юридические процессы — фиксирует технические точки контроля.

## 1. Категории персональных данных

| Данные | Где хранится | Срок (пилот) |
|--------|--------------|--------------|
| Идентификатор ребёнка (`child_profile_id`) | SQLite `child_profiles`, логи (session_id) | По политике центра, см. `docs/pilot/DATA_RETENTION.md` |
| Реплики диалога | RAM / `session_messages` при `SHORT_TERM_SOURCE=db` | STM: 15 пар; БД — по retention |
| Факты памяти (`long_term_memory_entries`) | SQLite | До `purge_child` / запроса родителя |
| Голос (если GUI) | Вне этого репозитория | Не сохранять без согласия |

## 2. Правовые основания и согласия

- Перед пилотом: **письменное согласие родителя** на обработку ПДн ребёнка и использование ИИ-наставника.
- В БД: поле `child_profiles.meta_json` → `{"parent_consent_at": "ISO8601", "parent_consent_version": "v1"}`.
- Env `REQUIRE_PARENT_CONSENT=true` — блокирует ходы без записанного согласия (см. `security/consent.py`).

Заполнить: [pilot/PASSPORT.md](pilot/PASSPORT.md), бланк согласия — у центра.

## 3. Трансграничная передача (LLM)

| Параметр | Env | Действие центра |
|----------|-----|-----------------|
| Endpoint LLM | `LLM_BASE_URL` | Указать юрисдикцию провайдера (РФ / EU / US) |
| Регион (справочно) | `COMPLIANCE_LLM_REGION` | Заполнить для отчётности, напр. `RU` или `EU` |
| Модель | `LLM_MODEL` | Договор с процессором / DPA |

**Рекомендация пилота:** endpoint в РФ или EU с DPA; не отправлять в prompt лишние ПДн (ФИО, адрес, телефон).

## 4. Технические меры в коде

- Модерация входа/выхода: `config/moderation.yaml`, опционально `MODERATION_API_URL`.
- Rate limit: `RATE_LIMIT_BACKEND=redis` + `REDIS_URL` для нескольких инстансов.
- Redact логов: `LOG_REDACT_USER_TEXT=true`, `LOG_REDACT_TOOL_ARGS=true`.
- `web_search` выключен по умолчанию (`WEB_SEARCH_ENABLED=false`); не в детских режимах YAML.
- Удаление ПДн: `center-agent-purge-child`.

## 5. Инциденты и эскалация

- `data/security_incidents.jsonl` — модерация, rate limit, consent, эскалация (`moderation_escalation`, `notify_pedagogue: true`).
- On-call: [pilot/ONCALL.md](pilot/ONCALL.md).
