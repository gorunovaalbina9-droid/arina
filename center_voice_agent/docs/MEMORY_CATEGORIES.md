# Категории долгосрочной памяти

Агент может записывать факты только в **разрешённые категории** (`memory/categories.py`):

| Категория | Пример |
|-----------|--------|
| `name` | Как зовут ребёнка (если согласовано с родителем) |
| `hobby` | Любит рисовать, играет в футбол |
| `preference` | Предпочитает короткие задания |
| `progress` | Прошёл урок про дроби |
| `note` | Заметка педагога (нейтральная) |

Запрещено записывать через агента без юридического согласования: адрес, телефон, медицинские диагнозы, данные родителей.

Инструменты: `memory_upsert`, `memory_search`. При `PREFETCH_LONG_TERM_MEMORY=true` последние записи подмешиваются в системный промпт до вызова LLM.

В `memory_search` символы `%` и `_` в запросе экранируются (SQL `LIKE … ESCAPE '\'`). Тест: `test_memory_search_like_escape` в `tests/test_memory_repository.py`.

Краткая память в БД: [SHORT_TERM_DB.md](SHORT_TERM_DB.md). Отчёт родителю: [PARENT_PROGRESS_REPORT.md](PARENT_PROGRESS_REPORT.md).
