# Инструменты и MCP

Бизнес-логика инструментов живёт в `src/center_voice_agent/tools/impl/` (по мере роста репозитория) и регистрируется в `TOOL_BY_ID`.

## Принцип «одна логика — два входа»

1. **LangChain** — `langchain_core.tools.tool` обёртки для `bind_tools` у LLM.
2. **MCP** — отдельный stdio/WebSocket сервер вызывает те же функции (следующий коммит): JSON-schema инструмента = контракт для обоих.

## Список инструментов v1

| ID | Назначение |
|----|----------------|
| `web_search` | Поиск в сети |
| `memory_search` | Чтение долгой памяти из БД |
| `memory_upsert` | Запись фактов (whitelist категорий) |

Режимы подключают инструменты списком `tool_ids` в YAML без изменения Python.
